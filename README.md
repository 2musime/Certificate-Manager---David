# 📄 Certificate Manager App

A web-based Certificate Management System developed during my time at Code of Africa, designed to streamline the creation, assignment, tracking, and storage of digital certificates.

## 🔧 Technologies Used
- **Frontend:** React.js (TypeScript), HTML5, CSS3
- **Backend:** ASP.NET Core Web API (C#)
- **Database:** SQL Server
- **Others:** Entity Framework Core, IndexedDB (for offline support), Postman (for API testing), GitHub (for version control)

## ✅ Core Features
- **Create & Upload Certificates** (PDFs)
- **Assign Users** to specific certificates (many-to-many relationship)
- **Add & View Comments** per certificate
- **Mobile-Responsive Design**: Clean and accessible layout for both desktop and mobile
- **Filter & Search** through certificates by supplier, user, or keyword
- **Secure Data Handling** via Web API endpoints
- **Database Migrations** using EF Core

## 📱 Responsive Design
Special care was taken to ensure the app is fully responsive, with a consistent layout across mobile, tablet, and desktop devices using clean CSS and flexible UI components.


## 🚀 Highlights
- Implemented CRUD operations for all major entities (Certificates, Users, Comments)
- Focused on clean UI/UX and consistent error handling
- Integrated PDF file preview and secure storage
- Real-world Git and GitHub workflow applied throughout the project

## 🧪 Testing & Debugging
- Tested API endpoints with Postman/Swagger
- Used browser dev tools for debugging layout and responsiveness
- Handled browser compatibility issues
